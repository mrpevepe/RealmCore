RealmCore

Backend de um MMORPG desenvolvido com Java e Spring Boot.

-- Objetivo --

O RealmCore é um projeto pessoal desenvolvido com o objetivo de aprimorar minhas habilidades em desenvolvimento backend, arquitetura de software, bancos de dados e boas práticas de desenvolvimento.

O projeto simula a estrutura de backend de um MMORPG, incluindo sistemas como contas, personagens, inventário, itens, combate, quests e mundo.

-- Tecnologias --
Java 21
Spring Boot
Spring Data JPA
Hibernate
PostgreSQL
Maven
Git
-- Arquitetura --

O projeto utiliza uma abordagem de Modular Monolith, organizando o código por domínio/funcionalidade.

A estrutura será construída gradualmente conforme novos sistemas forem implementados.

-- Objetivo de aprendizado --

Além de desenvolver o sistema, este projeto será utilizado para estudar e aplicar conceitos de desenvolvimento backend na prática.

Entre os conceitos que serão explorados:

APIs REST
Spring Boot
JPA / Hibernate
PostgreSQL
Validação
Tratamento de exceções
Testes automatizados
Autenticação e autorização
Docker
Redis
WebSocket
Mensageria
CI/CD

Tecnologias e conceitos mais avançados serão introduzidos conforme surgirem necessidades reais no projeto.
